## Plataforma

## Dificuldade
Very Easy

## Ferramentas

## Aprendizados
- Identifiquei o serviço Apache httpd em funcionamento na porta 80
- Utilizei o conceito de SQL Injection para acessar o painel administrador
- Aprendi que usar `#` para comentários no MySQL será anulado tudo que vem após e consequentemente pulando a verificação da senha

## Conceitos praticados
- Enumeração de serviços
- Banco de dados MySQL
- SQL Injetion

## Mitigações
- Utilizar consultas preparadas (Prepared Statements)
- Uso de ORMs modernos (Object-Relational Mapping)
- Princípio de menor privilégio no Banco de Dados
